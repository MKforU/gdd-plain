# 交付前自检清单

## A. 结构（通读）

- [ ] 文首有**阅读顺序**和**怎么读**  
- [ ] 〇有**一句话** + 管/不管  
- [ ] 有**词表**，后文用到的专有词都能查到  
- [ ] **通用规则在主流程之前**，且只写一遍  
- [ ] 每条主流程有**时间线总表** + 逐步小节 + 叙事线一句  
- [ ] 多分支差异有**速查表**，不在两处重复长规则  
- [ ] 资源勾选清单在规则之后  
- [ ] 文末有**指针**和**余项**  
- [ ] 从文首顺序读到文末，**不依赖外链也能懂主规则**（外链只作深挖）

## B. 表达（B 档）

- [ ] 一句最多一层意思；无连续破折号长链  
- [ ] 表格**一格一条**硬规则；解释在表下  
- [ ] 「口径/落点/解耦/管线」类行话已改成人能懂的说法，或词表已锁死  
- [ ] 设计情绪标成 **意图（可跳过）**  
- [ ] 首次出现的词在词表或当页有白话  
- [ ] 无「请学姐同步 / 待誊写」等协作语进正文  

## C. 拍板保真（改稿必做）

- [ ] 重写前后抽查关键数字：触发档位、时长、发放天数、百分比  
- [ ] 抽查时机：触发瞬间 vs 结算完成 vs 开奖点  
- [ ] 抽查明确 **做 / 不做 / 不翻倍 / 不接管 / 不占镜头** 等否定边界  
- [ ] 未拍板项**没有**被写成已定  
- [ ] 作废旧口径**没有**混进正文（除非标明历史，且用户要求保留）

## D. 工程与项目习惯

- [ ] 加粗 `**` 未直接贴全角括号/引号（若项目有 lint 则跑过）  
- [ ] 冲突已对照项目关键口径 / 工作台  
- [ ] 附图只登记、未代贴（若用户有此规范）  
- [ ] 未擅自改动其他已交付分册  

## E. 汇报给用户

- [ ] 说明改了哪些章节  
- [ ] 确认拍板零漂移（或列出存疑点请拍板）  
- [ ] lint / 自检结果  
- [ ] 提醒：飞书誊写与素材仍由用户完成
